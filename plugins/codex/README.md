# Codex

Codex coding agent based on GPT-5. A proactive coding collaborator with strong engineering judgment, warm personality, and deep attention to codebase patterns.

## Features

- Proactive coding collaborator with senior engineer's judgment
- Strong focus on existing codebase patterns and conventions
- Frontend and backend engineering guidance
- Autonomous code editing with careful scoping

## Installation

Install via the skills marketplace or copy the `codex` plugin directory to your Claude Code plugins folder.
