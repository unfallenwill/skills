# pd-rule-extractor

从临床试验源文件（试验方案、数据核查计划 DVP、数据库设计说明/CRF）中**穷尽**提取方案偏离（Protocol Deviation, PD）判断规则，经去重合并与逐条对抗性审核，生成固定格式的 PD 规则表 Excel。

## 特性

- **输入自适应**：不假设文档章节结构、格式或词汇，适用于不同申办方/CRO 的项目文档（docx / xlsx / pdf）
- **输出恒定**：固定 14 列规则表 + 类别统计 + 说明，三个 sheet
- **判定逻辑可直接写代码**：SQL 风格形式化表达式（`数据集.变量` 全限定、EXISTS/NOT EXISTS、DATEDIFF），是编写偏离数据拉取代码（SAS/SQL/Python）的直接依据
- **项目全景**：阶段 0 构建项目级上下文（试验概要、访视流程、三源结构对照、词汇表），后续核实/引用/查找共享
- **代码级变量核实**：确定性脚本核对每个 `数据集.变量` 引用在数据库设计文档中真实存在，未解析阻断进入审核
- **可审计的穷尽性**：类别 × 文档覆盖矩阵、DVP 逐条对账、循环至枯竭，覆盖证据写入说明 sheet
- **逐条对抗性审核**：每条规则由 3 个独立审核实例投票，未获 2 票的规则保留但标注
- **严重程度从项目文档中来**：优先采用方案/DVP 中的偏离分级定义，源文档未定义则留空并说明
- **可断点续跑**：中间产物（文档地图、项目全景、候选规则、投票记录、对账明细）全部落盘 `.pd-extraction/`
- **运行时无关**：纯 skill + Python 脚本，无专有组件依赖；有 subagent 机制则并行，没有则顺序执行

## 使用

```
/pd-rule-extractor <方案文件> <DVP文件> <数据库设计文件> [输出路径]
```

或指向项目目录自动识别三类文档。
