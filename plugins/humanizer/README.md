# Humanizer

去除 AI 生成内容的"AI 味"：在忠实原文表达意图的前提下润色中文内容，使其符合人类写作与阅读习惯。

## 为什么需要它

让 AI"把文字改自然一点"通常没用——AI 味的根源正是模型自身的默认审美（工整排比、均匀的信息密度、面面俱到、模板化结构），凭直觉改写只会引入新的 AI 味。本插件把"AI 味"拆解为具体、可检查的特征清单，按清单逐项诊断、逐项处理，并以忠实原意为硬约束。

## 功能

- **四层诊断**：从词汇（高频词、空洞大词）、句式（排比滥用、句长均匀）、结构（总分总模板、bullet 滥用）、气质（无立场、过度 hedging、缺具体）四个层面识别 AI 痕迹
- **三档强度**：轻度（只动词汇句式）/ 标准（含结构调整，默认）/ 深度（允许重组段落、重新分配详略）
- **五种文体**：公众号/博客长文、技术文章/文档、营销/商业文案、社交媒体短文、口播脚本，各有专门规范（如口播允许听觉冗余、技术文档以克制为先）
- **透明输出**：改写成品 + 诊断报告 + 按类别的改动说明（含改写前后对照）——改了什么、为什么改，一目了然，方便否决个别改动
- **忠实红线**：不增删事实与观点、不改变立场、**不虚构细节与亲历**；需要真实素材的位置以"待补充建议"提示，绝不代写

## 安装

```bash
/plugin marketplace add unfallenwill/treadonsnow-skills
/plugin install humanizer@treadonsnow-skills
```

## 使用

**自动触发**——直接在对话里说：

> 帮这段文字去去 AI 味
> 这篇稿子太像 AI 写的了，改得像人写的
> 人性化润色一下这个文件：draft.md

**主动调用**：

```
/humanizer:humanize <文本或文件路径>
/humanizer:humanize 轻度 <文本>        # 只动词汇和句式
/humanizer:humanize 深度 draft.md      # 允许重组段落、调整详略
```

## 输出结构

每次润色输出五个部分：

1. **润色结果** — 成品全文（长文件写入 `原名.humanized` 文件）
2. **诊断报告** — 四层特征命中情况与严重程度
3. **改动说明** — 按类别归纳，每类附改写前后对照
4. **待补充建议** — 哪些位置补充真实经历/数据会显著提升（不代写）
5. **忠实性自查** — 确认信息点、观点、立场无变化

```
│           ├── blog.md                   # 公众号/博客长文
│           ├── tech.md                   # 技术文章/文档

│           ├── social.md                 # 社交媒体短文
│           └── script.md                 # 口播脚本（抖音/B站）

```
