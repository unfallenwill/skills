# AI 味特征清单（中文）

诊断和改写的依据。按四层组织：层级越深，越接近"像不像人"的本质，处理优先级越高——但受强度档位的编辑权限约束。

## 第一层：词汇

处理原则：**优先删除；删不掉就换成具体、朴素的说法**。禁止换成另一个套话词（把"赋能"换成"助力"等于没改）。

判断一个词是否要处理，看两点：删掉后句意是否受损（不受损 → 删）；能否换成更具体的表达（能 → 换）。两者都不行的少数情况保留。

### 连接与总结类

| 高频词 | 处理 |
|--------|------|
| 首先/其次/再次/最后（成套出现） | 删掉序号词，靠内容自身逻辑衔接；确需标序的操作步骤可保留 |
| 总而言之、综上所述、总的来说 | 直接删；结尾段若无新信息，整段删 |
| 值得注意的是、值得一提的是 | 删——真值得注意就直接说 |
| 不难发现、我们可以看到、由此可见 | 删 |
| 事实上、实际上（高频出现时） | 大多数可删，保留真正表转折澄清的一两处 |
| 需要指出的是、必须强调的是 | 删 |

### 空洞升华类

| 高频词 | 处理 |
|--------|------|
| 随着……的发展、在……的今天/时代 | 删掉整个铺垫句，直接进入正题 |
| 日新月异、蓬勃发展、方兴未艾 | 删，或换成具体事实 |
| 新篇章、新格局、新纪元、未来已来 | 删 |
| 具有重要意义、扮演着重要角色、不可或缺 | 换成"重要在哪"的具体陈述 |
| 深远影响、极大地提升/推动 | 给出具体影响、提升多少；给不出就降调 |

### 商业黑话类

赋能、抓手、闭环、颗粒度、对齐、拉通、沉淀、组合拳、一站式、全方位、多维度、深度融合、极致体验、助力、加持——除非刻意模仿特定企业语境，一律换成直白说法。

### 形容词堆砌

强大的、优雅的、无缝的、丝滑的、革命性的、颠覆性的、令人惊叹的——形容词密度过高是显著 AI 特征。保留一个最准的，其余删掉；能用事实支撑的，把形容词换成事实。

## 第二层：句式

### 排比与对仗滥用

- **"不是……而是……"**：单独出现可以，全文两次以上必改。保留最有力的一处，其余改直陈。
- **三连排比**（"从 X 到 Y，从 A 到 B，从 C 到 D"）：AI 最爱的修辞。保留一项最重要的展开说，其余合并或删除。
- **四字词组连用**（"高效便捷、安全可靠、灵活易用"）：拆开，每个主张给依据；给不了依据的删。
- **对仗小标题**（"洞察本质 / 把握先机 / 赢得未来"）：改为直白描述内容的标题。

### 模板句式

- **冒号定义句**（"X：一个改变行业的存在"）：改为普通陈述句。
- **设问自答**（"为什么会这样？因为……"）高频出现：保留最多一处，其余改直陈。
- **"无论……还是……，都……"**：多数是伪全面。挑真正相关的情形直接说。
- **破折号滥用**：中文语境下"——"高频出现是翻译腔叠加 AI 味，多数可用逗号、句号替代。

### 节奏问题

- **句长均匀**：AI 生成句子的长度方差小。诊断：连续 5 句以上长度相近即命中。改法：该强调的压成短句，相邻次要句合并成长句。短句用于强调，长句用于铺陈。
- **"的"字定语链**（"基于云原生架构的面向企业级用户的一体化的解决方案"）：拆成两句，或把定语后置为补充说明。
- **一逗到底**：AI 改写腔常见。该断句就用句号。

## 第三层：结构

本层所有条目的修改需**标准档及以上**权限；标注（深度档）的条目需深度档权限。轻度档下只诊断、不修改，在报告中标注。

- **总分总强迫症**：开头预告全文、结尾复述全文。中间内容已完整时，开头直接进入主题，结尾停在最后一个实质内容上。
- **段末小结句**（每段最后一句重复本段大意）：直接删。
- **bullet 滥用**：列表只适合并列、无逻辑关联的短项。有因果或递进关系的内容用 bullet 是偷懒——回归成连贯句子。判断法：bullet 之间调换顺序会显得奇怪，说明它们有逻辑关系，应写成段落。
- **小标题过密**（深度档）：几百字一个小标题。合并小节，让内容自然流动——这属于段落重组。
- **强行升华结尾**（"让我们拭目以待"、"相信在不久的将来"）：删掉，结尾停在具体处。
- **信息密度均匀**（深度档）：AI 对每个点平均用力，人类有详有略。核心论点配案例展开，次要点一句带过甚至删除。
- **背景铺垫开头**（先讲一段人人皆知的行业背景）：删，从读者不知道的东西讲起。

## 第四层：气质

- **无立场、面面俱到**："当然，X 也有其价值"、"两者各有优劣"、"因人而异"。若原文实际有倾向，把倾向摆明，删掉和稀泥的套话；若原文真的中立，保持中立，但套话照删。**不得替作者发明立场，只能强化原文已有的倾向。**
- **过度 hedging**："可能"、"或许"、"在某种程度上"密集出现。原文有把握的判断，删掉不必要的软化词；原文本就不确定的，保留一处 hedging 即可。
- **过度热情**：惊叹号密集、"太棒了""令人兴奋"的 amazing 腔。降温，让事实自己说话。
- **对读者过度解释**：反复定义常识概念、"换句话说"高频出现。按目标读者水平删掉多余解释。
- **缺具体细节**：通篇抽象论述，没有数字、案例、场景。**这是唯一不能直接修的问题**——虚构细节违反红线。处理：在"待补充建议"中标注位置，说明补什么最有效。

## 过度矫正警告（改写后逐条自查）

以下"人味化"手法是反模式，效果比 AI 味更糟：

1. **强行语气词**：在书面文里撒"呢、啦、哈哈、嘛"。口语化 ≠ 语气词，真正的口语化是用词和句式的选择。
2. **强行热梗**：插入网络流行语显得"接地气"。热梗过时快、与上下文脱节，且本身已成为新的 AI 味。
3. **假装亲历**（红线）：编造"我上周试了一下"、"我们团队踩过这个坑"。这是虚构事实，任何档位都禁止。
4. **为变化而变化**：把通顺的句子改成别扭的句子制造"不完美感"。人类的不完美是自然产生的，刻意模仿只会难读。
5. **全文口语化**：把书面文体整体改成聊天腔。文体得体性优先于口语化。

## 严重程度标准（用于诊断报告）

- **轻**：某层特征出现 1-2 次
- **中**：某层特征出现 3-5 次，或多层各有零星命中
- **重**：某层特征贯穿全文，或结构层、气质层显著命中

结构层与气质层的命中比词汇层更严重——词汇好换，气质难改。报告中按此标注。
